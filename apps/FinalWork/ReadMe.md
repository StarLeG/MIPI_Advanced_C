# Программа вычисления площади фигуры, ограниченной тремя кривыми

## Описание задачи

Данная программа предназначена для вычисления площади фигуры, образованной тремя кривыми:

`f₁(x) = 0.6x + 3` (линейная функция)

`f₂(x) = (x - 2)³ - 1` (кубическая функция)

`f₃(x) = 3 / x` (гиперболическая функция)

Фигура ограничена точками пересечения этих функций. Требуется найти эти точки и вычислить площадь методом численного интегрирования.

## Структура проекта

Проект организован по модульному принципу и включает следующие компоненты:

### Заголовочные файлы (inc/)

`functions.h` — определение математических функций f₁, f₂, f₃ и их производных

`root.h` — модуль для поиска корней уравнений f(x) = g(x)

`integral.h` — модуль для численного интегрирования

`plotting.h` — модуль для визуализации графиков с помощью gnuplot

### Исходные файлы (src/)

`functions.c` — реализация функций и их производных

`root.c` — реализация комбинированного метода поиска корней (секущих и бисекции)

`integral.c` — реализация адаптивного метода Симпсона

`plotting.c` — генерация данных и скриптов для построения графиков

`main.c` — основная программа с обработкой аргументов командной строки

### Тестирование (test/)

`test_main.c` — комплексное тестирование всех модулей

### Сборка (CMakeLists.txt)

Файл конфигурации для сборки проекта с помощью CMake

## Алгоритмы и методы

### Поиск корней (root.c)

Для нахождения точек пересечения функций используется комбинированный метод, сочетающий:

`Метод секущих` — для быстрой сходимости вблизи корня

`Метод бисекции (половинного деления)` — для гарантии нахождения корня на интервале

Функция `root(f, g, a, b, eps1)` находит решение уравнения `f(x) = g(x)` на отрезке `[a, b]` с точностью `eps1`.

### Для вычисления определённых интегралов используется адаптивный метод Симпсона, который:

Автоматически разбивает интервал интегрирования на подынтервалы

Оценивает локальную погрешность на каждом подынтервале

Уточняет разбиение там, где это необходимо для достижения заданной точности `eps2`

Функция `integral(f, a, b, eps2)` возвращает структуру с результатом интегрирования и количеством выполненных итераций

### Визуализация (plotting.c)

Модуль визуализации:

Находит точки пересечения функций

Генерирует файлы с данными для построения графиков

Создаёт скрипт для gnuplot

Запускает gnuplot для отображения графиков и сохраняет результат в PNG-файл

## Интерфейс командной строки

Программа поддерживает следующие опции:


|        Опция        |                        Назначение                            |
|---------------------|--------------------------------------------------------------|
| `-h, --help`        | 	Вывод справочной информации                              |
| `-a, --abscissas`   | Вывод абсцисс точек пересечения                              |
| `-i, --iterations`  | Вывод количества итераций для приближённых решений           |
| `-t, --test`        | Запуск тестирования функций поиска корней и интегрирования   |
| `-p, --plot`        | Построение графиков функций с помощью gnuplot                |    
| `--eps1 ЗНАЧЕНИЕ`   | Установка точности для поиска корней (по умолчанию: 1e-6)    |
| `--eps2 ЗНАЧЕНИЕ`   | Установка точности для интегрирования (по умолчанию: 1e-4)   |

## Примеры использования

### Базовый расчёт площади

```bash
./area_calc
```

### Вывод абсцисс точек пересечения

```bash
./area_calc --abscissas
```

### Вывод информации об итерациях

```bash
./area_calc --iterations
```

### Комбинированный вывод

```bash
./area_calc --abscissas --iterations
```

### Запуск тестов

```bash
./area_calc --test
```

или

```bash
./tests_area_calc
```

### Построение графиков

```bash
./area_calc --plot
```

### Настройка точности вычислений

```bash
./area_calc --eps1 1e-8 --eps2 1e-6
```

### Получение справки
```bash
./area_calc --help
```

## Сборка проекта

### Требования

`Компилятор C` (поддерживающий стандарт C99)

`CMake` (версия 3.10 или выше)

`Gnuplot` (опционально, для построения графиков)

### Инструкция по сборке

```bash
# Создание директории для сборки
mkdir build
cd build

# Конфигурация проекта
cmake ..

# Сборка
make

# Запуск программы
./area_calc
```

### Тестирование

Проект включает два уровня тестирования:

### Модульное тестирование

`test_root()` — проверка поиска всех трёх пересечений функций

`test_integral()` — проверка интегрирования на тестовых интервалах с известными аналитическими значениями

### Интеграционное тестирование

`tests_area_calc` — комплексная проверка всех компонентов в связке

Для запуска тестов используйте:

```bash
./area_calc --test
```

или

```bash
./tests_area_calc
```

## Визуализация результатов

При запуске с ключом `--plot` программа:

Находит точки пересечения с заданной точностью

Сохраняет координаты точек в файл `intersections.txt`

Создаёт скрипт `plot_script.gp` для gnuplot

Запускает gnuplot для отображения графиков

Сохраняет изображение в файл `functions_plot.png`
